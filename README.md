# Ternix-TernixOS

Ternix（TritOS）探索三进制与 Unix 风格系统的结合。这里先把项目中的代数设想整理为可检验的数学基础；它们是研究方向，不代表内核或相关功能已经实现。

## 特征 3 的代数基础

使用
\[
\mathbb F_9 = \mathbb F_3[i]/(i^2+1)
\]
作为三进制特征域的最小扩张。因为 \(-1\) 在 \(\mathbb F_3\) 中不是平方，\(i^2=-1\) 给出真正的二次扩张。其加法群是 \(C_3\times C_3\)，乘法群 \(\mathbb F_9^\times\) 是循环群 \(C_8\)，并有唯一的 \(C_4\) 子群。

Frobenius 映射
\[
\varphi(x)=x^3
\]
是 \(\mathbb F_9\) 的自同构，满足 \(\varphi^2=\mathrm{id}\)，并逐点固定 \(\mathbb F_3\)。在乘法群上，它将元素映为其三次幂。

对任意 \(k\geq0\)，令 \(n=4k+2\)，则
\[
1^n+i^n=1+(i^2)^{2k+1}=1+(-1)=0=0^n.
\]
因此 \(n=2,6,10,\ldots\) 都满足所列恒等式；这是 \(\mathbb F_9\) 中的零值族。

## 其他研究方向

- **十二进制**：作为独立的表示/用户界面基数研究。它不是特征 3 的域，也不应与 \(\mathbb F_9\) 混为一谈。
- **辫群与拓扑**：\(B_n\) 由生成元 \(\sigma_1,\ldots,\sigma_{n-1}\) 及关系 \(\sigma_i\sigma_j=\sigma_j\sigma_i\)（\(|i-j|\geq2\)）、\(\sigma_i\sigma_{i+1}\sigma_i=\sigma_{i+1}\sigma_i\sigma_{i+1}\) 定义；它也对应平面上 \(n\) 个点的无序构形空间的基本群。可作为未来拓扑模型的基础。
- **指数塔**：若采用十二进制塔，需明确括号约定；例如右结合递推 \(T_0=1,\ T_{m+1}=12^{T_m}\)。
- **幻方与球谐矢量场**：目前是待定义的探索主题。需要另行指定幻方的阶数/运算，以及球面、向量场和球谐基的约定，才能形成可验证的实现需求。

本仓库目前没有内核、构建系统或测试框架。实现这些方向前，应先确定它们与 trit 表示、系统调用及目标硬件之间的接口。
